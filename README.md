## 安全须知（重要）

网页上的「同步到仓库」按钮会调用 GitHub API 触发工作流，需要一个 **细粒度 PAT**：

- 权限范围：**仅本仓库**
- 权限内容：**仅 Actions: write**（不要给 contents 写权限）
- 该 token 会出现在 `docs/app.js` 中，**任何人都能看到**

**已知风险**：token 泄露后，他人可以触发本仓库的确认工作流。工作流会校验输入格式，
因此攻击者最多能写入一个格式合法的确认日期，**无法写入任意内容、无法读取其他 Secrets、
无法影响其他仓库**。这是在「跨设备同步确认状态」需求下能做到的最小暴露面。

**若要彻底消除风险**：删除 `docs/app.js` 中的 token，改为点击按钮跳转到
GitHub Actions 手动运行页面（需自己登录，零 token）。
